# Shift Swap (Vite)

Simple Vite + React project wrapper around the provided `shift-swap.jsx` component for Vercel deploy.

Scripts:
- `npm run dev` — starts dev server
- `npm run build` — builds for production (Vercel will run this)
- `npm run typecheck` — runs `tsc --noEmit` to typecheck JS files (with `checkJs` enabled)
